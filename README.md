# Pentagrama

Editor de partituras para Windows: escribe música con el teclado, el mouse o un piano en pantalla, escúchala y expórtala a PDF, MIDI o MusicXML.

## Descargar

👉 **[Descargar la última versión](https://github.com/frantier/pentagrama/releases/latest)**: baja el archivo `Pentagrama-Setup-x.y.z.exe` y ábrelo.

> Windows puede mostrar «Windows protegió tu PC» porque el instalador todavía no está firmado digitalmente.
> Haz clic en **Más información → Ejecutar de todas formas**.

## Actualizaciones

Pentagrama revisa solo si hay versiones nuevas. Cuando hay una, aparece el botón **Actualizar** arriba a la derecha: un clic, se descarga, y con **Reiniciar** queda instalada.
